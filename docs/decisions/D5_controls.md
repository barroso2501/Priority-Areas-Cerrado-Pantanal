# D5 — Control design for Q2

**Status:** Open · **Raised:** 2026-10-02

## Context
Priority areas were selected for remnant vegetation and (in 2012) low cost, including low deforestation probability. Inside-only comparisons cannot separate designation from selection.

## Options
1. **Matched grid cells** (1 km² or H3) outside priority areas, protected areas and indigenous lands, with difference-in-differences.
2. Synthetic control per stratum (importance class × state).
3. Synthetic "placebo polygons" with the same size and shape distribution.

## Matching covariates (baseline period)
% native vegetation, physiognomy, slope, agricultural suitability, distance to roads and towns, state, ecoregion, neighbourhood conversion rate in the prior period.

## Recommendation
Option 1, with tests for parallel pre-trends. Decide after Phase 1 descriptive results.

## Expected limitations
- Designation is indicative, so effects are likely small.
- Possible anticipation (2012–2016) and leakage to neighbouring cells.
